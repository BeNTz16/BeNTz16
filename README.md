### 🌱 Karbonify

> Karbonify is a social platform I co-founded. It calculates carbon footprints and gamifies eco-friendly actions.

- 🗺️ **Map** — recycling bins, polluted areas, and location-based tasks
- 🤝 **Events** — cleanup meetups, attendance/check-ins, event rooms, and gallery
- 🏆 **Gamification** — XP, daily tasks, streaks, leagues, and leaderboard
- 📸 **Eco-photo** — photo verification, moderation queue, and admin panel
- 🔔 **PWA** — web push notifications and mobile-first interface
